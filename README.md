# Library Management System

## 📌 Project Overview

The Library Management System is a console-based application developed using C++ to automate library operations such as managing books, borrower records, and book transactions. The system reduces manual work and improves the accuracy and efficiency of library management.

---

# 🎯 Objectives

- Automate library management processes
- Manage books and borrower records efficiently
- Implement CRUD operations for books and borrowers
- Provide secure user authentication and access control
- Maintain persistent data storage using file handling

---

# 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL Vector
- File Handling
- VS Code
